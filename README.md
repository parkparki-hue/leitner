# لایتنر (PWA) — نسخه ۲

## ساختار ریپو
```
index.html
manifest.webmanifest
sw.js
icons/
decks/
   index.json      ← فهرست فروشگاه دسته‌ها
   *.csv           ← هر دسته یک فایل
```

## افزودن دسته به فروشگاه
1. فایل CSV با ستون‌های `word,meaning,tag` را در `decks/` بگذارید (برچسب اختیاری است).
2. یک ردیف به `decks/index.json` اضافه کنید:
```
{ "id": "en-ielts", "name": "انگلیسی — آیلتس", "lang": "en", "desc": "...", "file": "en-ielts.csv", "count": 50 }
```
   زبان‌های مجاز: `en`، `ar`، `fr`، `de`، `tr`، `es`.
3. Commit کنید. کاربر در «بانک ← فروشگاه دسته‌ها» دسته را می‌بیند و اضافه می‌کند. افزودن دوباره فقط لغات جدید را اضافه می‌کند.

## فروشگاه از ریپوی دیگر
در «تنظیمات ← آدرس فروشگاه» می‌شود آدرس کامل یک `index.json` دیگر (مثلاً در ریپوی CMS) را داد. GitHub Pages اجازه خواندن از دامنه دیگر را می‌دهد.

## به‌روزرسانی
بعد از تغییر `index.html` یا آیکون‌ها، مقدار `V` در `sw.js` را بالا ببرید. تغییرات `decks/` فوراً دیده می‌شود.

## داده کاربر
- کلیدهای قبلی localStorage حفظ شده و «انگلیسی» و «عربی» به‌صورت دو دسته اولیه باقی می‌مانند.
- «کد انتقال» (فشرده‌شده و متنی) برای انتقال به گوشی دیگر؛ فایل JSON هم پشتیبان کامل است.
