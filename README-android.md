# ساخت APK (WebView) از ریپوی لایتنر
1. محتوای این پوشه را (شامل `.github` و `android`) در ریشهٔ ریپوی `leitner` کپی و Commit کنید.
2. در GitHub: تب Actions ← «Build APK» ← Run workflow (با هر Push روی main هم خودکار اجرا می‌شود).
3. بعد از پایان، از بخش Artifacts فایل `leitner-apk` را دانلود کنید؛ داخلش `app-debug.apk` است.
4. APK را روی گوشی نصب کنید (نصب از منبع ناشناس را فعال کنید).
نکته: وب‌اپ داخل APK بسته‌بندی می‌شود و آفلاین کار می‌کند؛ فروشگاه دسته‌ها فقط با اینترنت از آدرس تنظیم‌شده خوانده می‌شود.
